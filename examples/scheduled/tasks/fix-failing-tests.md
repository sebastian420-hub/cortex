Run the project's tests. If any fail, find the cause in the source code and fix it.

Rules:
- Fix the code, not the tests. Do not delete, skip or weaken a test to make it pass. If you are
  convinced a test is wrong, leave it alone and say so in your final message.
- Keep each change small and in the style of the surrounding code.
- Do not add dependencies or change configuration files.
- You cannot ask questions. If something is ambiguous, choose the most conservative option and
  describe your assumption in the final message.

When you finish, say in two or three sentences what was wrong and what you changed.
