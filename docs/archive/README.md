# Archive

Plans, summaries and fix notes from earlier stages of the project, kept for history. They describe
what someone intended or believed at the time, not what the code does now: many name features that
were never built or have since changed, and some use the project's old name (LocalAgent). For the
current state read [STATUS.md](../STATUS.md) and [CORTEX_TECHNICAL_SPEC.md](../CORTEX_TECHNICAL_SPEC.md).
