Features
--------

* **Multi-Model Support**: Use Claude, GPT-4, DeepSeek, Ollama, and more
* **Intelligent Routing**: Automatically select the best model for each task
* **Powerful Tools**: File operations, git, search, AST analysis, and more
* **Plugin System**: Extend functionality with custom tools
* **Permission Modes**: Control what actions are allowed
