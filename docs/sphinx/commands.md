# Commands Reference

See the full [COMMANDS.md](../COMMANDS.md) documentation.

## Quick Reference

### File Operations

| Command | Description |
|---------|-------------|
| `read_file` | Read file contents |
| `write_file` | Write to a file |
| `edit` | Edit file with search/replace |
| `glob` | Find files by pattern |
| `grep` | Search file contents |

### Git Operations

| Command | Description |
|---------|-------------|
| `git_status` | Show repository status |
| `git_diff` | Show changes |
| `git_log` | Show commit history |
| `git_commit` | Create a commit |

### Code Analysis

| Command | Description |
|---------|-------------|
| `ast_search` | Search using AST patterns |
| `ast_extract` | Extract code elements |
| `ast_analyze` | Analyze code structure |

### Web Operations

| Command | Description |
|---------|-------------|
| `web_fetch` | Fetch web page content |
| `web_search` | Search the web |
