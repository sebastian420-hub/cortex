## 1. Overview

Cortex is an **OS-native autonomous agent** — a privileged, persistent, cognitive process
that uses the computer the way a skilled human operator would. It runs as a system service,
boots with the machine, perceives the environment through OS-level APIs and accessibility
tools, plans multi-step tasks using an embedded cognitive loop, and executes those tasks
through a rich, permissioned tool system.

Unlike traditional automation scripts, RPA tools, or stateless LLM wrappers, Cortex:

- **Remembers** — semantic long-term memory with recency, relevance, and importance scoring
- **Plans** — multi-step goal decomposition with replanning on failure
- **Feels** — optional emotion and personality model that modulates decision-making
- **Coordinates** — multiple Cortex instances form a workforce, sharing state and tasks
  across machines through a central backend

The AI Ecosystem simulation (FastAPI + PostgreSQL + Qdrant + Redis + Unity) serves a dual
role: as a **safe cognitive testbed** for validating agent behavior before it touches a real
machine, and as the **coordination backend** for multi-agent networks.

## 2. Design Philosophy

### Agents as Users, Not Tools

Cortex is not a plugin or a helper. It is registered as an OS user with its own account,
home directory, process namespace, and permissions. Every action it takes is traceable to
that identity, auditable, and sandboxed to appropriate scope.

### Cognition Before Action

Before Cortex does anything, it perceives, recalls, and plans. The cognitive loop
(Perceive → Remember → Decide → Act → Reflect) runs on every tick, producing structured
decisions with explicit reasoning rather than reactive command execution.

### Safety is Structural, Not Bolted On

Permission modes, command filtering, sandboxing, rollback checkpoints, and audit logs are
first-class architectural components — not afterthoughts. Auto mode (full autonomy) is
explicitly gated behind configuration and logging requirements.

### The Simulation is the Lab

Every new cognitive behavior is validated in the AI Ecosystem simulation before being
promoted to control a real machine. The simulation and the real agent share the same
cognitive core, differing only in the environment adapter they use.

### One Agent, Network of Instances

A single Cortex instance is powerful. A coordinated network of them, each controlling its
own machine and sharing memory and task state through the backend, is a workforce. The
architecture supports both from day one.

## 5. OS Integration Layer

### 5.1 The `cortex` User Account

Cortex runs under a dedicated OS user — not root, not the human user. This is the
foundation of its sandboxing model.

```bash
# Linux setup
sudo useradd -r -m -s /bin/bash -d /home/cortex cortex
sudo mkdir -p /opt/cortex /etc/cortex
sudo chown cortex:cortex /opt/cortex
```

**Filesystem scope:**

```
/opt/cortex/          → Cortex installation root (full RW)
/etc/cortex/          → System-wide config (read-only at runtime)
/home/cortex/         → Agent home, local state, memory cache
/var/log/cortex/      → Audit and event logs
/tmp/cortex/          → Ephemeral scratch space
```

Human project directories are accessed via ACLs or explicit allowlist in config —
never assumed.

    async def start(self):
        """Boot the agent — restore state, register, begin loop."""
        await self.session.restore()
        await self.memory.initialize()
        await self.tool_registry.load_all()
        await self.cognitive.initialize()

    async def run_loop(self):
        """
        Core autonomous loop.
        Runs continuously on heartbeat tick.
        """
        while self.running:
            try:
                # 1. Perceive current environment
                context = await self.cognitive.perceive()

                # 2. Retrieve relevant memories
                memories = await self.memory.retrieve(
                    query=context.summary,
                    limit=self.config.memory_recall_limit
                )

                # 3. Make a decision
                decision = await self.cognitive.decide(
                    context=context,
                    memories=memories,
                    tools=self.tool_registry.list_available(),
                    goals=self.session.active_goals
                )

                # 4. Validate against security policy
                approved = await self.security.check(decision)
                if not approved:
                    await self.audit.log_blocked(decision)
                    continue

                # 5. Execute the action
                if decision.action:
                    result = await self.execute_action(decision)

                    # 6. Reflect and store memory
                    await self.cognitive.reflect(
                        context=context,
                        decision=decision,
                        result=result
                    )

                    await self.memory.store(
                        content=decision.observation,
                        action=decision.action,
                        result=result,
                        importance=decision.importance_score
                    )

                    await self.audit.log_action(decision, result)

            except Exception as e:
                await self.handle_error(e)

            await asyncio.sleep(self.config.tick_interval)

    async def execute_action(self, decision: Decision) -> ActionResult:
        """Route decision to appropriate tool and execute."""
        tool = self.tool_registry.get(decision.action)
        if not tool:
            raise ToolNotFoundError(decision.action)
        return await tool.execute(**decision.arguments)

    async def handle_error(self, error: Exception):
        """Graceful error handling with optional rollback."""
        await self.audit.log_error(error)
        if self.config.auto_rollback:
            await self.memory.state.rollback_last()

# cortex/cognitive/personality.py

@dataclass
class PersonalityModel:
    """
    Big Five personality traits + Cortex-specific traits.
    Range: 0.0 (low) to 1.0 (high)
    Set per agent instance in config.
    """
    # Big Five
    openness:          float = 0.8   # Creativity, curiosity
    conscientiousness: float = 0.9   # Discipline, thoroughness
    extraversion:      float = 0.3   # Talkativeness (low = quiet agent)
    agreeableness:     float = 0.7   # Cooperation with user/other agents
    neuroticism:       float = 0.2   # Anxiety, instability (low = stable)

    # Cortex-specific
    risk_tolerance:    float = 0.4   # Willingness to take bold actions
    persistence:       float = 0.85  # Retries before giving up
    curiosity:         float = 0.75  # Proactive exploration tendency
    caution:           float = 0.8   # Preference for safe operations


# cortex/cognitive/emotions.py

@dataclass
class EmotionState:
    """
    Six-channel emotion model. Updated after each action result.
    Influences prompt tone, risk tolerance, and retry behavior.
    Range: 0.0 to 1.0
    """
    joy:      float = 0.5
    sadness:  float = 0.1
    anger:    float = 0.0
    fear:     float = 0.1
    surprise: float = 0.2
    trust:    float = 0.7

    def update(self, result: ActionResult, personality: PersonalityModel):
        """Adjust emotions based on action outcome."""
        if result.success:
            self.joy   = min(1.0, self.joy + 0.1)
            self.trust = min(1.0, self.trust + 0.05)
            self.fear  = max(0.0, self.fear - 0.05)
        else:
            self.sadness = min(1.0, self.sadness + 0.1 * personality.neuroticism)
            self.fear    = min(1.0, self.fear + 0.05)
            self.joy     = max(0.0, self.joy - 0.05)

    def risk_modifier(self) -> float:
        """
        Returns a multiplier applied to risk_tolerance.
        High fear or sadness reduces willingness to take bold actions.
        """
        return 1.0 - (self.fear * 0.4) - (self.sadness * 0.2)

### 7.5 Decision Engine

```python
# cortex/cognitive/decision.py

@dataclass
class Decision:
    """Structured output from the LLM decision step."""
    action:          str
    arguments:       Dict[str, Any]
    reason:          str
    observation:     str
    importance_score: float          # 0.0–1.0, used for memory storage
    follow_up:       Optional[List[str]]  # Planned next steps
    confidence:      float           # Model's self-reported confidence


class DecisionEngine:
    """
    Constructs prompts from context + memories + personality/emotions,
    calls the LLM provider, and parses structured decisions.
    """

    SYSTEM_PROMPT = """
You are Cortex, an OS-native autonomous agent. You control a computer
on behalf of your operator. You perceive the environment, recall memories,
and decide what action to take next using available tools.

Your personality:
{personality}

Your current emotional state:
{emotions}

Always respond with a JSON decision object. Never take actions outside
your permitted tool set. When uncertain, use the plan tool to decompose
your goal further before acting.
"""

    async def decide(
        self,
        context: PerceptionContext,
        memories: List[Memory],
        tools: List[ToolSchema],
        personality: PersonalityModel,
        emotions: EmotionState,
        goals: List[Goal],
    ) -> Decision:

        system = self.SYSTEM_PROMPT.format(
            personality=personality.to_prompt(),
            emotions=emotions.to_prompt()
        )

        user_prompt = self._build_user_prompt(context, memories, goals)

        response = await self.provider.complete(
            messages=[
                Message(role="system", content=system),
                Message(role="user", content=user_prompt),
            ],
            tools=tools,
            temperature=self._adjusted_temperature(emotions, personality),
        )

        return self._parse_decision(response)

    def _adjusted_temperature(
        self,
        emotions: EmotionState,
        personality: PersonalityModel
    ) -> float:
        """
        Higher curiosity + joy → slightly higher temperature (more creative).
        Higher fear + neuroticism → lower temperature (more conservative).
        """
        base = 0.7
        base += personality.curiosity * 0.15
        base -= emotions.fear * 0.2
        base -= personality.neuroticism * 0.1
        return max(0.1, min(1.0, base))
```

## 9. Memory Architecture

Cortex uses a four-tier memory system that maps to how humans remember things:

```
┌───────────────────────────────────────────────────────┐
│                   MEMORY TIERS                        │
│                                                       │
│  TIER 1 — Working Memory (in-context)                 │
│  ┌─────────────────────────────────────────────────┐  │
│  │ Current conversation + last N tool calls        │  │
│  │ Active plan steps + immediate observations      │  │
│  │ Duration: current tick / turn                   │  │
│  └─────────────────────────────────────────────────┘  │
│                          │                            │
│  TIER 2 — Session Memory (local, in-process)          │
│  ┌─────────────────────────────────────────────────┐  │
│  │ Full task history for this session              │  │
│  │ Tool call results, errors, retries              │  │
│  │ Duration: current agent session                 │  │
│  └─────────────────────────────────────────────────┘  │
│                          │                            │
│  TIER 3 — State Memory (local disk)                   │
│  ┌─────────────────────────────────────────────────┐  │
│  │ Checkpointed state snapshots                    │  │
│  │ Rollback targets                                │  │
│  │ Duration: persistent across reboots             │  │
│  └─────────────────────────────────────────────────┘  │
│                          │                            │
│  TIER 4 — Long-Term Memory (Qdrant + Postgres)        │
│  ┌─────────────────────────────────────────────────┐  │
│  │ Semantic vector store of all memories           │  │
│  │ Scored by: recency × relevance × importance     │  │
│  │ Duration: permanent (shared across network)     │  │
│  └─────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

### 9.1 Memory Scoring

Based on the Park et al. generative agents paper, memories are retrieved using a
composite score:

```python
# cortex/memory/longterm.py

class MemoryScorer:
    """
    Scores memories for retrieval using three dimensions:
    recency, relevance, and importance.
    """

    RECENCY_DECAY   = 0.995   # Per-hour decay factor
    RECENCY_WEIGHT  = 1.0
    RELEVANCE_WEIGHT = 1.0
    IMPORTANCE_WEIGHT = 1.0

    def score(
        self,
        memory: Memory,
        query_embedding: List[float],
        now: datetime
    ) -> float:
        recency   = self._recency_score(memory.created_at, now)
        relevance = self._relevance_score(memory.embedding, query_embedding)
        importance = memory.importance   # Scored by LLM at storage time (0–1)

        return (
            self.RECENCY_WEIGHT    * recency    +
            self.RELEVANCE_WEIGHT  * relevance  +
            self.IMPORTANCE_WEIGHT * importance
        )

    def _recency_score(self, created_at: datetime, now: datetime) -> float:
        hours_elapsed = (now - created_at).total_seconds() / 3600
        return self.RECENCY_DECAY ** hours_elapsed

    def _relevance_score(
        self,
        memory_embedding: List[float],
        query_embedding: List[float]
    ) -> float:
        return float(cosine_similarity(memory_embedding, query_embedding))
```

### 10.4 Task Routing

```python
# cortex/backend/services/coordinator.py

class TaskCoordinator:
    """
    Routes tasks to the most capable and available agent.
    Uses capability matching + load balancing + trust scores.
    """

    async def assign_task(self, task: Task) -> AgentAssignment:
        # Get all online agents
        candidates = await self.get_online_agents()

        # Filter by required capabilities
        capable = [
            a for a in candidates
            if all(cap in a.capabilities for cap in task.required_capabilities)
        ]

        if not capable:
            raise NoCapableAgentError(task.required_capabilities)

        # Score candidates
        scored = [
            (agent, self._score_agent(agent, task))
            for agent in capable
        ]
        scored.sort(key=lambda x: x[1], reverse=True)

        best_agent = scored[0][0]
        return await self._assign(best_agent, task)

    def _score_agent(self, agent: AgentRecord, task: Task) -> float:
        load_score    = 1.0 - (agent.active_tasks / agent.max_concurrent)
        trust_score   = agent.trust_score             # 0.0–1.0
        latency_score = 1.0 / (1.0 + agent.avg_latency_ms / 1000)
        return (load_score * 0.4) + (trust_score * 0.4) + (latency_score * 0.2)
```
